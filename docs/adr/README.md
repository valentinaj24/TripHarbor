# Arhitekturne odločitve (ADR)

Dokumenti so pripravljeni po minimalni predlogi MADR in utemeljujejo arhitekturne odločitve projekta TripHarbor.

Za novo odločitev kopirajte `adr-template.md` in ustvarite datoteko z naslednjo zaporedno številko. Ob spremembi sprejete odločitve dodajte nov ADR ter navedite, katerega nadomešča. Starega ADR ne brišite.
